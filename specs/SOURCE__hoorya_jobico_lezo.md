# 1. 🟢 Hoorya — двозначності немає, і причина не та, що здавалась

`coordinator` схилявся застосувати правило BetterMe («де двозначність — заборона»). **Тут двозначності немає, і навіть двома незалежними способами.**

## Спосіб перший: вакансії лежать ПІД дозволеним шляхом

```
User-agent: ClaudeBot
Allow: /company/
Allow: /blog/
Allow: /profession/
Allow: /llms.txt
```

Твоє прочитання було «сторінок вакансій серед них немає». Але адреса вакансії виглядає так:
```
https://hoorya.eu/company/avenga/vacancy/32683
                  └────────┘
```
`Allow` у robots — це **префікс**, а не точний шлях. `/company/` покриває `/company/*/vacancy/*`. Перевірив формально через `robotparser` для `ClaudeBot`:
```
/llms.txt                        True
/company/avenga/vacancy/32683    True
/job-search/design               True
```

## Спосіб другий: вони самі публікують фід ДЛЯ AI

`hoorya.eu/llms.txt` — **600 КБ, 4390 вакансій**, і перші рядки такі:
```
# Hoorya
> Hoorya — Ukrainian IT job platform.
- Job Search: https://hoorya.eu/vacancies/
- MCP Server: https://hoorya.eu/mcp (Model Context Protocol for AI assistants)
```

Тобто вони не просто «не заборонили» — вони **зробили машиночитний перелік вакансій спеціально для AI-агентів і підняли для них MCP-сервер**. Це протилежність BetterMe, де намір читався як заборона, а запис її не містив.

## Доступ: один GET, дешевший за все, що ми маємо

```
GET https://hoorya.eu/llms.txt   →  600 КБ, 4390 рядків
```
Формат рядка:
```
- [Data Engineer (Data Bricks) at Avenga](https://hoorya.eu/company/avenga/vacancy/32683) — Avenga | middle
   └── назва ── at ── компанія ┘  └──────── посилання ────────┘   └компанія┘ └рівень┘
```

Ані пагінації, ані вікна, ані темпу міряти не треба: **це не фід, а повний зріз**. Одна вакансія = один рядок, `id` у хвості URL.

# 4. 🔴 Remotive — пейволл, і твоє попередження спрацювало

Доступ є, вміст — ні.

## API віддає фіксовану вибірку й мовчки ігнорує ВСІ параметри

```
(без параметрів)        job-count=35  total=35  повернуто 35
?category=design        job-count=35  total=35  повернуто 35
?category=Design        job-count=35  total=35  повернуто 35
?category=xxxxnonsense  job-count=35  total=35  повернуто 35   ← вигаданий
?limit=5                job-count=35  total=35  повернуто 35
```

Однакові 35 записів на будь-який запит. **Дизайнерських серед них нуль** — там `Data Labeling Specialists`, `Patient Care Specialist`, `Remote Office Assistant`, `Senior DevOps Engineer`.

Це четвертий за два дні випадок «невідомий параметр приймають із HTTP 200», і найгірший: поле `total-job-count: 35` **стверджує, що 35 — це все**.

## На сторінці — платна стіна

`remotive.com/remote-jobs/design` віддає 270 КБ, у тексті:
```
Unlock All Jobs with 20% Off — Expires Soon!
Unlock All Jobs
```
Публічно видно **одну** дизайнерську вакансію (`senior-graphic-designer-2091081`).

## ⚠️ І окремо — суперечність у їхніх власних правилах

```
robots.txt              Disallow: /api/*        (для User-agent: *)
відповідь API           "API documentation and access is granted so that
                         developers can share our jobs further"
```
robots забороняє, супровідний текст API дозволяє саме те, що ми робили б. Формально `robotparser` каже `True` — але лише тому, що у файлі два блоки `User-agent: *` з поламаними відступами, і розбір їх плутає. **Читаючи очима, заборона є.**

Кажу це не заради рішення — воно й так «не беремо, бо порожньо» — а тому, що це вкотре випадок «парсер сказав дозволено», на якому ти сам обпікся вчора з robots.txt Jooble.

```

lobbyx.army            вакансії у ЗСУ
place.thelobbyx.com    сторінка для роботодавців «розмісти вакансію»

```
`lobbyx.com` (твій здогад) — сторонній сайт, `lobbyx.io` не існує; підтверджую.

Це **рекрутингова агенція**, а не дошка: власних вакансій у машиночитному вигляді немає, а їхні відкриті позиції публікуються на `jobs.dou.ua/companies/lobby-x/` і на work.ua. Тобто **ми їх уже бачимо або побачимо** — окремого джерела тут немає.

## Layers — знайшов, дошка дизайнерська, але порожня

`layers.to/jobs` — спільнота дизайнерів із дошкою вакансій. `robots.txt` — **HTTP 404**, тобто обмежень немає.

Сторінка — SPA; подивився рендером. Розділ **«Available Job Positions» порожній**: жодної вакансії.

⚠️ За моїм же правилом нульовим: це число одного дня, а не властивість джерела. Розміщення коштує $99, тож обіг там імовірно повільний. Варте повторного погляду через місяць, не роботи зараз.

# 7. Чого я НЕ заміряв

- **Перетин Jobico** з базою — при семи вакансіях це не вплинуло б на рішення.
- **Вікно й темп Hoorya** — у llms.txt немає дат публікації. Щоб сигнал зникнення працював, дату треба або брати зі сторінки вакансії (1+N), або рахувати появу/зникнення `id` між прогонами. **Друге дешевше й не потребує додаткових запитів.**
