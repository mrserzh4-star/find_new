> Вердикт: 🟢 **брати** · ціна ~2 год · **дає сегмент, якого немає ні на DOU, ні на Djinni.**

## 0. Чому це не «ще один борд»

Головний аргумент — не обсяг, а **неперетинання**. Порівняв роботодавців дизайн-вакансій HappyMonday з роботодавцями `category=Design` на DOU:

**Перетин — 2 з 19.** Спільні лише `SKELAR` і `Headway Inc`. Решта 17 на DOU не зустрічаються взагалі:

| сегмент | роботодавці |
|---|---|
| креативні агенції | OMGAgency, Okay Monday Agency, Mccann Kyiv, iProspect |
| медіа | MEGOGO, Ukraїner |
| **громадський сектор / NGO** | Глобальний договір ООН в Україні, Фонд підтримки реформ, ГО «АЛЬЯНС.ГЛОБАЛ», 1-й окремий медичний батальйон |
| edtech / продукт | Mate academy, Quests Inc, PlayMe Studio |

Це рівно той сегмент, який ми шукали після висновку по топ-50: **дизайнерів наймають агенції та студії, а не аутсорс-гіганти.** DOU і Djinni — IT-борди, вони цей прошарок не бачать. Особливо NGO/громадський сектор — його немає на IT-бордах у принципі.

## 1. Спосіб доступу

**WordPress REST API. Без ключа, без авторизації.**

```
GET https://happymonday.ua/wp-json/wp/v2/job?per_page=100&after=2026-07-26T00:00:00
```

| | |
|---|---|
| Метод | `GET` |
| Заголовки | не потрібні |
| Відповідь | `application/json`, HTTP 200 |
| Платформа | WordPress, кастомний тип запису `job` |

Знайдено через `"/wp-json/wp/v2/types"` — там серед типів є `job` з `rest_base: "job"`. Це дешева перевірка (один запит), варта того, щоб пробувати її на кожному новому кандидаті-борді.

`robots.txt` дозволяє: заборонені лише `/profile/`, `/manage/` та їхні локалізовані версії. Розділ вакансій і API відкриті.

⚠️ **`https://happymonday.ua/feed` — це БЛОГ, не вакансії.** Виглядає як очевидний RSS-кандидат, але віддає редакційні статті («Чи працюють українці у відпустці?»). Не переплутати.

## 2. Мапа полів → наша схема

| Наше поле | Звідки | Як |
|---|---|---|
| `source` | — | константа `"happymonday"` |
| `title` | `title.rendered` | ⚠️ HTML-сутності: `Brand &amp; UI/UX` → потрібен `unescape` |
| `company` | `title.rendered` | ⚠️ **окремого поля НЕМА** — тільки з заголовка, див. нижче |
| `location` | `class_list` | префікси `country-*` і `city-*` |
| `url` | `link` | напряму, вже канонічний |
| `tags` | `class_list` | префікси `job_category-*`, `job_global_category-*` |
| `posted_at` | `date` | ISO-8601, локальний; є ще `date_gmt` — брати його |

### Чого немає (не додумувати)

- **Окремого поля компанії немає.** Роботодавець зашитий у заголовок за схемою `{посада} до {компанія}` (укр.) або `{посада} at {компанія}` (англ.). Тобто та сама проблема, що й у DOU, лише з іншим роздільником. Розділяти по `\s+(?:до|at)\s+` з кінця.
  ⚠️ Формат не гарантований: трапляються `Product Designer` без компанії взагалі і `VFX Artist – Freelance` з тире. На вибірці 22 дизайн-вакансій компанію вдалося виділити у 19.
- **`job_city` порожній** у переглянутих записах, `acf` порожній. Локацію брати **тільки з `class_list`**, не з цих полів.
- **Локація заповнена не завжди:** з 22 дизайн-вакансій тег країни мали лише 7. Тобто `location` для цього джерела часто буде `None` — це нормально і не привід відкидати запис.
- Немає зарплати, немає грейду окремим полем, немає дати протухання.

## 3. Фільтри на боці джерела

| Параметр | Приклад | Статус |
|---|---|---|
| `after` | `?after=2026-07-26T00:00:00` | ✅ **працює** — за датою публікації |
| `modified_after` | `?modified_after=…` | ✅ працює (691 проти 41 808 без нього) |
| `per_page` | `?per_page=100` | ✅ максимум **100**; `101` → HTTP 400 `rest_invalid_param` |
| `page` | `?page=2` | ✅ **справжня пагінація** |
| `orderby` / `order` | `?orderby=date&order=desc` | ✅ працює |
| `search` | `?search=designer` | ⚠️ працює, але **шукає по всьому тексту** — «Комунікаційний менеджер» матчиться на слово в описі. Для точності не годиться. |
| `job_category` | `?job_category=dyzajn` | ❌ **ІГНОРУЄТЬСЯ МОВЧКИ** |

### 🔴 Той самий footgun, що в DOU і Djinni

`?job_category=dyzajn` і `?bogusparam=1` обидва віддають `X-WP-Total: 41808` — тобто повний нефільтрований набір. Таксономії `job_category` **не виставлені в REST** (в `/wp-json/wp/v2/taxonomies` їх немає), тому параметр просто відкидається.

**Наслідок:** фільтрувати за категорією можна **тільки на клієнті**, по `class_list`. Це третє джерело з чотирьох, де невідомий параметр не падає, а тихо знімає фільтр — білий список параметрів треба робити спільним для всіх адаптерів, а не для кожного окремо.

Перевірка валідації тут усе ж є, але часткова: `per_page=101` чесно віддає HTTP 400. Тобто валідуються «рідні» параметри WP, а чужі ігноруються.

## 4. Пагінація — є, справжня

`per_page` (макс. 100) + `page`. Заголовки відповіді:

```
X-WP-Total: 41808
X-WP-TotalPages: 419
```

⚠️ `X-WP-Total: 41808` — це **всі вакансії за всю історію**, включно з давно неактуальними, а не «зараз відкрито». Не використовувати як показник обсягу.

Робочий спосіб інкрементального забору — `after` за міткою останнього прогону:

| запит | `X-WP-Total` |
|---|---|
| `?after=2026-07-20` | 213 |
| `?after=2026-07-25` | 22 |
| `?after=2026-07-26` | 17 |

Тобто на щогодинний цикл — **один запит**, який поверне одиниці записів.

## 5. Стабільний ID

`id` — ціле (`1915320`). Він же в URL: `https://happymonday.ua/jobs/1915320`. Слаг у посиланні не бере участі, тож перейменування вакансії URL не змінює.

Ключ дедупу: `("happymonday", id)`.

## 6. Обсяг і свіжість — заміряно

Вибірка: **500 найсвіжіших вакансій**, що покривають **19 діб** (08.07–27.07).

- дизайнерських (`job_category-dyzajn`): **22** = 4.4%
- темп: **~1.2 дизайн-вакансії на добу**, ~35 на місяць
- **інженерного сміття: 0.** Категорія `dyzajn` чиста — жодного `Інженер-конструктор` чи `Electronics Design Engineer`, на відміну від DOU. **Стоп-лист не потрібен.**

Тобто за обсягом HappyMonday приблизно на рівні DOU (25 у вікні), але **без сміття і з іншими роботодавцями**.

## 7. Ризики

| Ризик | Оцінка |
|---|---|
| Авторизація | не потрібна |
| Анти-бот / Cloudflare | **не спостерігав**, голий `urllib` проходить |
| `robots.txt` | дозволяє; заборонені лише `/profile/`, `/manage/` |
| Rate-limit | не спостерігав (~10 запитів поспіль, 5 з них по 100 записів) |
| Playwright | не потрібен |
| Крихкість API | **низька** — стандартний WP REST, не саморобка |
| Крихкість парсингу компанії | **середня** — роздільник `до`/`at` у заголовку, формат не гарантований (19 з 22) |
| Мовчазна деградація | `job_category` ігнорується без помилки; якщо хтось спробує фільтрувати на сервері — отримає всі 41 808 записів і не помітить |
| Порожні локації | 7 з 22 мають країну. Не баг, але `location` часто буде `None` |

## 8. Вердикт

🟢 **Брати. Третім джерелом після Djinni і DOU.**

- Ціна: ~2 год (WP REST + клієнтський фільтр по `class_list` + парсер компанії з заголовка).

- Один запит на цикл, справжня пагінація, справжні дати, нуль сміття.

**Головна цінність — не обсяг, а 17 з 19 унікальних роботодавців:** креативні агенції, медіа й громадський сектор, яких на IT-бордах немає. Це прямо закриває прогалину, яку виявив замір по топ-50.
